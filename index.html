The Engine & The Rules

Expectiminimax Game Tree

Monopoly is a stochastic game of alternating player choices (deterministic decision nodes) and random dice rolls (chance nodes). This project models decision-making with an Expectiminimax game tree:

  • Max nodes (AI turn): the agent evaluates every legal action — buy, pass, build, mortgage, unmortgage, jail strategy.
  • Chance nodes (dice rolls): outcomes over all eleven roll values (2–12), weighted by the binomial probability P(d) = (6 − |7 − d|) / 36.
  • Min nodes (opponents): opponent counter-actions and future rent payments.

State Evaluation Heuristic

At the search horizon, states are scored with dynamic weighted features:

V(s) = w_cash·Cash + w_prop·Equity + w_mono·Monopolies + w_dev·HouseROI + w_inc·E[Rent] − w_haz·E[Hazard]

Dynamic strategy adaptation: weights shift between the early game (rapid expansion), mid game (completing color sets, the 3-house sweet spot), and late game (liquidity preservation — and staying in jail to avoid opponent hotels).

Win Conditions

Win by reaching the target balance ($4,000), or drive every opponent into bankruptcy through lethal rent traps.
